#### 🔬 Research

**[ReproMut](https://github.com/Hamjeth68/repromut)** — a controlled mutation benchmark for ML reproducibility. I break small ML experiments on purpose (unset seeds, stale caches, hidden `.env` overrides, dependency drift) and measure which checks notice. On 452 planted cases, a seed check caught 29% of the faults that changed results and a config comparison 73%; re-running caught them all.

- Preprint (v0.3): [doi.org/10.5281/zenodo.24090849](https://doi.org/10.5281/zenodo.24090849)
- Write-up: [*Your seed is fixed. Your ML result still changed.*](https://medium.com/@hamjeth-misree/your-seed-is-fixed-your-ml-result-still-changed-914954549740)
